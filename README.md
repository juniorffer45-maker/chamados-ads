## Objetivo do Projeto: 
Construir e criar uma de API que atue com a função de Chamados de Suporte.


## Como executar
Para inicializar a aplicação, no terminal, digite o comando "uv sync". Isso irá instalar todas as bibliotecas e funções necessárias para o funcionamento da aplicação, além de abrir automaticamente o Ambiente Virtual (.venv)

Para executar, digite "uv run flask --app app run --host=0.0.0.0 --port=5000" ou "Flask Run" no terminal
